## Convenções

- **Atual:** evidência no snapshot/runtime.
- **Planejado Wn:** aprovado, ainda não entregue.
- **Opcional:** pode estar off por default ou indisponível por policy.
- **Restrito:** exige papel/capability.
- **Experimental:** não deve ser prometido como estável.

Nenhum guia substitui authZ do servidor, política da organização ou instrução de
segurança.
